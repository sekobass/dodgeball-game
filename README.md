# ドッジボールゲーム Ver.0.1

小学生でも楽しめる、見下ろし型の2Dドッジボールゲーム。青チーム3人と赤いCPUチーム3人で対戦します。

## あそび方

`index.html` をPCのブラウザで開き、「スタート」を押してください。インストール、ビルド、外部ライブラリ、通信、APIキーは不要です。HTML/CSS/JavaScriptのみのためGitHub Pagesでも配信可能です（公開設定は変更していません）。

- 矢印キー / WASD：青いリングの選手を移動
- Space：一番近い相手へ自動照準で投球
- 地面のボールに近づく：自動で拾う。黄色いリングが保持者の目印
- 「はじめから」：対戦を初期状態に戻す

中央線は越えられません。飛んでいる相手のボールに当たるとアウトです。壁に当たるか一定時間が経つとボールは地面に落ち、拾えるようになります。相手全員をアウトにすると勝利、自分のチームが全員アウトになると敗北です。操作中の選手がアウトになると生存中の味方へ自動交代します。味方2人とCPU3人は自動行動します。

## 開発

- `index.html`：画面と操作説明
- `style.css`：レスポンシブ表示
- `game.js`：Canvas描画、経過時間ベースのゲームループ、入力、AI、判定、状態管理

直接ファイルを開くほか、必要ならリポジトリで `python3 -m http.server 8000` を実行して静的配信できます。
