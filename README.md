# ドッジボールゲーム Ver.0.6

小学生でも楽しめる、見下ろし型の2Dドッジボールゲームです。青チームと赤チームが、内野3人・外野2人ずつで対戦します。青内野の1人をプレイヤーが操作し、ほかの選手はAIが操作します。

## あそび方

PCのブラウザで `index.html` を開いて「スタート」を押します。インストール、ビルド、外部ライブラリ、APIキーは不要です。

| 操作 | キー |
| --- | --- |
| 青いリングの選手を移動 | 矢印キー / WASD |
| 一番近い相手内野に投球 | Space |
| 一番近い味方外野にパス | P |
| 相手の投球をキャッチ | 当たる直前に C |
| 地面のボールを拾う | ボールに近づく |

キャッチの受付は0.25秒間で、再使用まで1秒かかります。黄色いリングはボール保持者の目印です。「はじめから」で初期配置に戻ります。

## 外野と勝敗

コートは左から赤外野、青内野、赤内野、青外野です。内野と外野はそれぞれのエリア内で移動し、外野からの投球はエンドラインの外側から行います。

- 相手内野への攻撃と、味方の内野・外野間のパスができます。パスは受け手が受け取り、軌道に入った相手内野はアウトにならずにボールを奪えます。
- 相手の攻撃が内野に当たると、その選手はチームの外野へ移動します。操作中の選手なら、別の青内野に操作が切り替わります。
- 「復帰可」の外野は、自分の攻撃を相手内野に当てると内野に戻れます。「初期」の外野は試合を通して外野を担当します。パスやキャッチされた攻撃での復帰はありません。
- 相手の内野を0人にすると勝ちです。試合時間に制限はありません。

内野AIはボールを取るとセンターライン付近まで前進し、相手内野への投球か味方外野へのパスを選びます。相手の攻撃は前後どちらから来ても軌道を予測して回避します。外野AIは担当エリアでボールを拾い、相手内野への攻撃か味方内野へのパスを選びます。地面のボールが6秒間拾われないと、中央付近に戻ります。

「ゆっくり／ふつう／はやい」でボールの初速を選べます。試合開始から10秒ごとに初速の1/6ずつ加速し、120秒で初速の3倍に達します。飛んでいるボールの速度は投球・パス時点で決まります。

## 開発とテスト

- `index.html` と `style.css` は画面と操作説明を担当します。
- `game.js` はCanvas描画、入力、AI、ゲームルールを担当します。
- `node --test` で人数、境界、投球・パス、復帰、勝敗、速度、回避、長時間動作を検証できます。

HTTP経由で確認する場合は、リポジトリで `python3 -m http.server 8000` を実行してください。ゲームはPCのキーボード操作向けです。
