# ドッジボールゲーム Ver.0.4

小学生でも楽しめる、見下ろし型の2Dドッジボールゲーム。青チーム3人と赤いCPUチーム3人で対戦します。

## あそび方

`index.html` をPCのブラウザで開き、「スタート」を押してください。インストール、ビルド、外部ライブラリ、通信、APIキーは不要です。HTML/CSS/JavaScriptのみのためGitHub Pagesでも配信可能です（公開設定は変更していません）。

- 矢印キー / WASD：青いリングの選手を移動
- Space：一番近い相手へ自動照準で投球
- 地面のボールに近づく：自動で拾う。黄色いリングが保持者の目印
- 「はじめから」：対戦を初期状態に戻す

中央線は越えられません。飛んでいる相手のボールに当たるとアウトです。壁に当たるか一定時間が経つとボールは地面に落ち、拾えるようになります。相手全員をアウトにすると勝利、自分のチームが全員アウトになると敗北です。試合時間は無制限で、どちらかのチームが全滅したときに決着します。CPU選手と味方AIはボールを持っていなくてもセンターライン寄りに積極的に前進します。CPU選手はボールを持つとまずセンターライン直前まで前進し、相手を狙って投げます。操作中の選手は自分でセンターラインに近づき、Spaceキーで投げます。ボールが拾われない場合は一定時間後に中央付近へ戻ります。操作中の選手はボールを持ってSpaceキーを押すと投げます。操作中の選手がアウトになると生存中の味方へ自動交代します。味方2人とCPU3人は自動行動します。

## 開発

- `index.html`：画面と操作説明
- `style.css`：レスポンシブ表示
- `game.js`：Canvas描画、経過時間ベースのゲームループ、入力、AI、判定、状態管理

直接ファイルを開くほか、必要ならリポジトリで `python3 -m http.server 8000` を実行して静的配信できます。

## Ver.0.1の確認

Chromiumでローカル静的サーバー経由の起動、キーボード入力、ゲームループ、再開、狭い画面での横幅、JavaScript実行エラーなしを確認。状態を制御したテストで上下左右の移動、コート境界、取得・投球、CPU投球、当たり判定、人数更新、操作選手の交代、両チームの勝敗、リスタートを確認しています。

このクラウド環境ではブラウザポリシーが file:// を制限するため、ファイル直接表示は未検証です。Chrome / Edge個別の実機確認は未実施です。タッチ操作、音、キャッチ、外野、難易度選択は未実装です。操作はPCキーボード向けです。

## ボールの速さ（Ver.0.2）

制限時間はありません。画面の「ボールの速さ」で「ゆっくり／ふつう／はやい」を切り替えられます。開始から30秒で1.25倍、60秒で1.5倍、90秒で1.7倍に段階的に加速します。投げたボールは投球時点の速度で飛びます。

## 回避AI改善（Ver.0.4）

青チームの味方AI・赤チームCPUは、相手の投球中にボールの速度から通過予測位置を計算して上下に回避します。危険時はセンターラインから少し下がり、回避を短時間維持して不自然な左右の揺れを抑えます。相手がボールを持っている間は守備位置を少し下げて反応できる距離を確保します。操作中の青選手の移動は従来どおり手動です。試合時間は無制限のままです。
